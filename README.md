# BurnerfanXR
A minecraft plugin that trains the implemented DL4J library ai. It is trained by the movement the player makes. It only tracks a few things so it would be better if you made your own changes.

Use maven to clean package the whole entire thing.
# Tutorial
Install maven and set it up correctly in your environment varibales , PATH.
Then open cmd and do cd (The dir to the folder)
Then do *mvn clean package*
This should create a file named target and the main plugin will be inside it.
